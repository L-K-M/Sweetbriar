# M6.4 qualification: performance, accessibility and power cuts

Run these on the owner's Mac with the CI-built app of a merged commit
(O3: the `Sweetbriar-app` artifact). An agent may run them and records
itself as the runner (plan/README.md). It asks the owner before
entering credentials and before any effect on a real account.

Record the date, runner, commit, Mac model and macOS for every run,
failed runs included. A row nobody ran stays "not run". Never record
addresses, subjects or message text: the repository is public.

## 1. Performance budgets

Measure over the real mailbox (spec/08 "Performance budgets", spec/06's
search targets). Record the mailbox's message count and whether a sync
was running.

| Budget | Limit | Result |
|---|---|---|
| Warm launch | p95 400 ms | not run |
| Open a cached message | p95 100 ms | not run |
| Archive or delete, visible | p95 50 ms | not run |
| Archive or delete, durable intent | p95 100 ms | not run |
| Search results after the last keystroke | p95 100 ms | not run |
| Open compose | p95 100 ms | not run |
| Cached exact search during sync | p95 100 ms, p99 250 ms | not run |
| New mail searchable | p95 2 s | not run |
| Index rebuild | 15 min | not run |

The first six come from the opt-in latency log. Until the app has that
log they can't be recorded here. A missed budget is a finding, not a
limit to relax.

## 3. Power cuts

`kill -9`, Force Quit, Restart and Shut Down are not power cuts
(spec/11). On a desktop Mac, pull the power. A notebook has a battery:
disconnect it from power and hold the power button until it goes off,
and record that this stood in for pulling power. The owner decides
whether that counts.

A power cut stops every program on the Mac. Get the owner's agreement
on the time, and save and quit everything else first.

### Prepare

Use new roots, never the archive you rely on, and create both on the
internal disk. Record the volume's format.

```sh
ROOT="$HOME/sweetbriar-power-cut"
mkdir "$ROOT"
open -n -a /path/to/Sweetbriar.app --args \
  -dataRoot "$ROOT/data" -cacheRoot "$ROOT/cache"
```

The sync cut needs an account signed in to these roots, so it needs
the owner's credentials. Sending and filing aren't part of this test.

### Cut during a draft save

1. Open a new message. Type `power-cut save 1` in the body and wait for
   "Saved". That revision is acknowledged.
2. Append `, save 2`, wait for "Saved", and write down both markers on
   paper or another device.
3. Append `, save 3` and cut power while "Saving…" shows. Write down
   the last text that had shown "Saved".

### Cut during sync

1. Let the first sync start. Activity has no "syncing" word: it runs
   while the account's "indexed" line keeps changing.
2. Save a draft containing `power-cut sync 1` and wait for "Saved".
3. Cut power while sync is still running.

### Check, before the app opens again

After starting the Mac, make sure Sweetbriar didn't reopen
(`pgrep -x Sweetbriar` prints nothing). Check a copy, because opening
the database recovers its write-ahead log.

```sh
ROOT="$HOME/sweetbriar-power-cut"
COPY="$(mktemp -d)"
cp -p "$ROOT"/data/state.sqlite* "$COPY"/
sqlite3 "$COPY/state.sqlite" 'PRAGMA integrity_check; PRAGMA foreign_key_check;'
sqlite3 "$COPY/state.sqlite" \
  "SELECT seq, body_source FROM draft_revisions
   WHERE body_source LIKE 'power-cut %' ORDER BY draft_id, seq;"
```

The first query prints exactly `ok`. The second lists every revision
that had shown "Saved". The save in flight may be absent or whole, and
never partial.

Then launch the app on the same roots. The drafts open with that text,
no integrity warning shows, sync resumes and finishes, and Back Up Now
ends complete: it reads and hashes every referenced object, so a
missing or damaged one fails it.

| Run | Every acknowledged save | Integrity | Sync resumed | Backup complete | Result |
|---|---|---|---|---|---|
| Draft save | | | n/a | | not run |
| Sync | | | | | not run |

Keep the roots of a failed run and report it. After a passing run,
disconnect the account in the app, then delete the test roots and the
copies.

# Topic: Eudora (classic Mac and Windows email client)

Leads to check, not facts to repeat: Steve Dorner at UIUC (1988), Qualcomm
(Eudora Light / Eudora Pro, sponsored mode), Eudora 6/7, end of development
in 2006, Eudora OSE / Penelope (Thunderbird-based), the Computer History
Museum's release of the Eudora source code (2018), Eudora's mbox-based
storage, filters, nicknames, "personalities", stationery, plug-ins,
MoodWatch, Redirect, Send Again, Make Filter, Make Nickname, the
"Out"/"In"/"Trash" mailboxes, status columns, labels, priorities, server
status (leave on server / delete from server), "Find Messages", the
Eudora junk scoring, and its famous usability on dial-up. Look for the
manuals (Eudora User Manual PDFs), the CHM blog post and source, and
user reminiscences (e.g. "I still use Eudora" posts, the HERMES/Eudora
users lists, "Eudora on Windows 10/11" communities).

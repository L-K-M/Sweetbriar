## Common questions for this classic client

1. History: who made it, when, platforms, major versions, business story,
   why it declined or died, and what happened to the code and the team.
2. Feature inventory: list every notable feature you can find, as
   concretely as possible (menu commands, preferences, file formats, filter
   actions, keyboard behaviour). Prefer primary sources: manuals, help
   files, read-me files, release notes, the vendor's old web site via the
   Wayback Machine (web.archive.org), and archived download pages
   (macintoshgarden.org, archive.org, info-mac mirrors).
3. What users loved: quotes and paraphrases from contemporary reviews
   (Macworld, MacUser, TidBITS, MacInTouch, Low End Mac, MacFixIt, Ars
   Technica, magazines on archive.org) and later reminiscences (Hacker News,
   Reddit, blogs, mailing lists). What made it feel good to use: speed,
   control, text handling, workflow, personality?
4. What users disliked, and its limits.
5. Lost features: which of its features are missing or worse in today's
   mainstream clients (Apple Mail, Outlook, Gmail, Spark, Thunderbird,
   Mimestream)?
6. Re-imagining for 2026: for each feature worth reviving, how would it
   work in a modern, native macOS client backed by IMAP/JMAP/Exchange? Note
   which need server support and which are purely client-side.

Mark clearly what is verified (with a link) and what is recollection or
unverified. Do not invent features.

# Topic: Eudora 6.2 for Macintosh, feature inventory from its user manual

`./sources/eudora62-mac-manual.txt` is the OCR text of the official
*Eudora 6.2 for Macintosh* user manual (Qualcomm, 2004;
https://archive.org/details/bitsavers_qualcommeual_8147561). It is a
primary source. A separate job inventories the source code; your job is
the user-facing view.

Read the manual in full and produce:
1. An exhaustive, structured inventory of features as the user experiences
   them: mailboxes and mail storage, the message list (columns, sorting,
   labels, priorities, status, server status), reading, composing (styles,
   stationery, signatures, nicknames/address book, spell check, MoodWatch,
   attachments, encodings), sending options (queueing, Send Again,
   Redirect, Forward, Reply-to-all variants), personalities (multiple
   identities), checking mail (POP/IMAP options, leave on server, skip big
   messages), filters (all criteria and actions, Make Filter), finding
   (Find Messages, search options), junk mail handling (scoring, plug-ins),
   plug-ins (EMSAPI translators), AppleScript, settings panels, keyboard
   shortcuts, statistics ("Usage Statistics"), sponsored/paid/light modes,
   and anything else.
2. For each feature: how it worked (cite manual page or section), and
   whether today's mainstream clients (Apple Mail, Outlook, Gmail,
   Thunderbird) have an equivalent.
3. The 15-25 most distinctive or beloved capabilities, with a proposal for
   reviving each in a modern native macOS client with IMAP/JMAP/Graph
   backends (Sweetbriar).
